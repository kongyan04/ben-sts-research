KD Paper — Proof Fitness Analysis

Does Appendix A analyze Algorithm 1's EMA-guided distillation? A component-by-component evaluation.
Paper: Mitigating Forgetting in Split Learning via Knowledge Distillation  ·  Reviewed May 2, 2026
What this page answers: The KD paper's main algorithmic contribution is sequential split learning with an EMA teacher and knowledge distillation loss. Appendix A provides a convergence proof. This page evaluates how well that proof actually fits the algorithm it claims to support — component by component.

Component-by-Component: Algorithm 1 vs. Appendix A

Algorithm structure: sequential vs. parallel

Algorithm 1 (what the paper does)
K clients train one at a time. Each client trains for \(E_\text{train}\) epochs before the next client begins.

In round \(r\): client 1 trains → client 2 trains → ... → client K trains → move to round \(r+1\).

Only one client is active at any moment. Server does not receive concurrent updates from multiple clients.
Appendix A (what the proof analyzes)
All K clients participate simultaneously each round (FedAvg-style).

Eq. 15 sums over \(m = 1 \ldots K\) clients simultaneously. Eq. 18 decomposes the joint update of all K clients at once.

This is the standard parallel SGD / FedAvg model from McMahan et al. 2017.

This is the most consequential fitness failure. A sequential algorithm and a parallel algorithm have fundamentally different convergence behavior. In sequential training, after client \(k\) finishes, the server model may drift before client \(k+1\) starts — this is precisely the forgetting phenomenon the paper studies and mitigates with KD. The proof does not model this drift at all.

Knowledge distillation loss

Algorithm 1 — combined loss
\[\mathcal{L} = (1-\lambda_e)\mathcal{L}_{CE} + \lambda_e \mathcal{L}_{KD}\] where \(\mathcal{L}_{KD} = T^2 \cdot KL(q^{(T)} \| p^{(T)})\)

Warm-start schedule: \(\lambda_e = 0\) for \(e \leq w\), then ramps to \(\lambda_{\max}\).

The KD term is the paper's main contribution for mitigating forgetting.
Appendix A — objective
Analyzes a generic smooth function \(f(\theta)\).

No \(\mathcal{L}_{KD}\), no KL divergence, no temperature \(T\), no \(\lambda_e\), no warm-start schedule.

The proof would apply equally to any L-smooth SGD objective.

The KD loss is the paper's entire contribution to mitigating forgetting. A fitness score of 0/10 is not an exaggeration — the object the proof is analyzing (\(f\)) is not the object the paper actually optimizes (\((1-\lambda_e)\mathcal{L}_{CE} + \lambda_e \mathcal{L}_{KD}\)). Moreover, \(\lambda_e\) changes during training (warm-start), making the objective non-stationary. Standard SGD convergence analysis assumes a fixed objective.

EMA teacher model

Algorithm 1 — EMA update
At the end of each epoch \(e\):
\[\theta_t^e = \beta \cdot \theta_t^{e-1} + (1-\beta) \cdot \theta_s^e \quad (\beta = 0.99)\]
The teacher is a running average of student weights — not trained by any gradient step.
Appendix A — teacher
No teacher model of any kind appears.

The symbol \(\beta_K\) appears in Eqs. 39–41 but is never defined and is not connected to the EMA decay \(\beta = 0.99\).

An EMA update is a convex combination, not a gradient step — it is incompatible with the proof's gradient-descent framework.

Sequential forgetting and client drift

What the paper studies
When client \(k+1\) starts training, it sees a server model that was last updated during client \(k\)'s training. The server has "forgotten" client \(k+1\)'s data distribution.

This is the core problem: sequential training causes the server to catastrophically forget earlier clients' representations as it adapts to each new client.
What the proof models
A stationary loss landscape \(f\) with bounded heterogeneity \(\zeta^2\) across clients.

No notion of the server drifting between one client's training period and the next. No forgetting, no non-stationarity across the sequential client schedule.

The non-stationarity induced by sequential client training is the central phenomenon the paper identifies, studies, and addresses with KD. The proof does not model it. This is not a minor gap — it is the entire motivating problem of the paper, and the proof provides no theoretical support for the claim that KD mitigates it.

The Fundamental Problem: Proof is FedAvg Convergence, Not KD Convergence

Bottom line: Appendix A proves that a generic parallel SGD algorithm with K clients, L local steps, and heterogeneous data converges at rate \(O(1/\sqrt{KLR})\). This is a correct and well-known result. It is not a convergence analysis for sequential split learning with knowledge distillation. The paper's main contribution — that EMA-guided distillation prevents forgetting in sequential split learning — receives zero theoretical support from the proof.

The proof is not wrong within its own context. The L-smoothness framework, variance bounds, and convergence rate are all standard results correctly derived. The problem is that the context — parallel FedAvg on a smooth stationary objective — is not the context of the paper.

Why the empirical results still stand

The paper reports strong empirical results: +13.7 percentage points on CIFAR-10 compared to sequential split learning without KD (Table I). These results are independent of the proof. Experiments do not depend on the convergence analysis in Appendix A being correct. The empirical contribution is the paper's primary strength and is not affected by the proof issues identified here.

What a correct proof would need to model, minimally:
  1. Sequential training order: prove descent when exactly one client trains per round
  2. EMA teacher: show that \(\theta_t = \beta\theta_t + (1-\beta)\theta_s\) provides a stable reference point (bounded \(\|\theta_t - \theta_s\|\))
  3. KD loss regularity: show that \(\mathcal{L}_{KD} = T^2 \cdot KL(q^{(T)}\|p^{(T)})\) is smooth (or provide a bound on its gradient) so the combined loss is L-smooth
  4. Warm-start non-stationarity: handle the changing weight \(\lambda_e\) — perhaps by analyzing each phase (pre-warm-start and post-warm-start) separately
