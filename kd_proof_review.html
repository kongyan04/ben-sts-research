The Biggest Gap: The Proof Does Not Analyze What It Claims to Analyze

Core finding: The proof in Appendix A is a correct convergence analysis for a parallel FedAvg-style algorithm with generic smooth loss. It is not a convergence analysis for Algorithm 1, which is sequential split learning with EMA-guided knowledge distillation. The paper's main contribution — the EMA teacher and the KD loss \(\mathcal{L}_{KD}\) — is entirely absent from the proof. The algorithm structure is also fundamentally different: parallel vs. sequential. The proof cannot be repaired by minor edits; it requires a different analytical approach.

Section-by-Section Analysis

Eq. 14 — L-smoothness descent — correct

The standard nonconvex descent lemma. \(\mathbb{E}[f(\theta+\Delta x) - f(\theta)] \leq \mathbb{E}[\langle\nabla f, \Delta x\rangle] + (L/2)\mathbb{E}\|\Delta x\|^2\). This is correct and applies to any L-smooth objective. No issues here.

Eq. 15 — Gradient expansion with K clients, L steps — mismatch

Algorithm 1 (sequential)
Round \(r\): client 1 trains for \(E_\text{train}\) epochs. Then client 2 trains. Then client 3. Only one client is active at any time.

\(\Delta x\) involves one client's updates, not K simultaneous clients.
Proof Eq. 15 (parallel)
Expands \(\langle\nabla f, \Delta x\rangle\) with a double sum over \(m=1\ldots K\) clients and \(l=1\ldots L\) steps simultaneously.

This is FedAvg: all K clients update in parallel each round.

The K summation in Eq. 15 assumes all K clients contribute to \(\Delta x\) in a single round. In Algorithm 1, only one client contributes per round. This is the most fundamental mismatch, and it propagates forward to Eq. 18 (4-term decomposition), Eq. 28 (main descent), and the final convergence rate.

Eqs. 16–17 — Young's inequality — correct

Standard technique to separate \(\langle a, b\rangle \leq \frac{1}{2}\|a\|^2 + \frac{1}{2}\|b\|^2\). No issues. These steps are independent of whether the algorithm is parallel or sequential.

Eq. 18 — 4-term decomposition — correct structure, wrong context

The split of \((L/2)\mathbb{E}\|\Delta x\|^2\) into four terms (stochastic variance, local drift, client heterogeneity, global gradient) is a standard technique from FedAvg analysis papers. The decomposition is mathematically valid. The problem is that terms 3 and 4 involve sums over K simultaneous clients — which is the wrong model for Algorithm 1.

Eqs. 19–24 — Variance and local drift bounds — correct

Terms 1 and 2 are bounded correctly. The variance bound using \(\sigma^2\) and the local drift bound via L-smoothness are both standard and valid for SGD with local steps.

Eqs. 25–27 — Sampling lemma — misapplied

Eq. 25–27 — Sampling without replacement
\[\mathbb{E}\|x - \bar{x}\|^2 = \frac{n-s}{s(n-1)}\zeta^2\] Applied to bound the heterogeneity term (Term 3) using \(\zeta^2\) (bounded data heterogeneity across clients).

This lemma applies when clients are selected by random sampling without replacement. Algorithm 1 uses a fixed sequential order: client 1 trains, then client 2, then client 3, ..., then client K, and repeats. There is no randomness in client selection. The sampling-without-replacement formula does not apply. The heterogeneity bound is therefore incorrect.

Eq. 28 — Main descent bound — correct form, wrong model

The main descent inequality \(\mathbb{E}[f(\theta^{r+1}) - f(\theta^r)] \leq -(1/6)KL\eta\|\nabla f\|^2 + \ldots\) is correct for the parallel FedAvg setting. But because it incorporates the K-parallel structure and the misapplied sampling lemma, it does not bound Algorithm 1's behavior.

Eqs. 29–38 — Second bounding of E_r — correct mechanics

The 4-term bounding of \(\mathbb{E}\|x_{m,l}-x\|^2\) and the sum bounds \(\sum\sum B_{m,k} \leq \frac{1}{2}K^2L^2\) are valid combinatorial results. These steps are technically correct for a multi-client multi-step SGD analysis.

Eq. 39 — E_r on both sides — skipped algebra

Eq. 39 — self-referential bound
\[E_r \leq 2K^2L^2\eta^2\sigma^2 + 2L^2K^2L^2\eta^2 E_r + \cdots + 2(\beta^2_K+1)K^3L^3\eta^2\|\nabla f\|^2\] \(\Rightarrow\) Eq. 41: \(E_r \leq \frac{9}{4}K^2L^2\eta^2\sigma^2 + \cdots\) (coefficient 9/4 asserted without derivation)

With \(E_r\) on the right side, one must rearrange: collect the \(E_r\) terms, factor, and divide. The learning rate constraint in Eq. 40 (\(\eta \leq \frac{1}{6LKL(1+\beta^2_K)}\)) is what makes this division valid. But the step from Eq. 39 to Eq. 41 is never shown. The coefficient 9/4 is asserted. This gap should be filled explicitly.

The undefined \(\beta_K\)

The symbol \(\beta_K\) appears in Eq. 39–41 and in the learning rate constraint Eq. 40. It is never defined. Given the notation, one might guess it is meant to relate to the EMA decay \(\beta = 0.99\) in Algorithm 1, but no such connection is drawn. If it is the EMA parameter, then \(\beta_K\) and \(\beta\) should be the same symbol with an explicit definition. If it is something else (e.g., a bound related to the K-th client), it needs to be introduced.

Eqs. 42–52 — Substitution and weighted averaging — correct

Given the bound from Eq. 41, the substitution into the main descent and the subsequent weighted averaging lemma (Eqs. 48–52) are standard and correctly applied. The technique is the same used in FedAvg convergence proofs.

Eqs. 53–57 and Theorem 1 — correct form, broken references

The optimal learning rate \(\eta^* = O(1/\sqrt{KLR})\) and the resulting convergence rate \(O(1/\sqrt{KLR})\) are the expected results for a parallel algorithm. Theorem 1 then cites "Assumptions (1),(6),(15),(18)" — but these are equation numbers in the appendix, not labeled Assumption environments. There are no environments titled "Assumption 1," "Assumption 6," etc. in the text. The references are broken.

The Two Critical Absences

1. The KD loss is entirely missing

Algorithm 1 uses a combined loss:

Algorithm 1 — combined loss
\[\mathcal{L} = (1-\lambda_e)\mathcal{L}_{CE} + \lambda_e \mathcal{L}_{KD}\] where \(\mathcal{L}_{KD} = T^2 \cdot KL(q^{(T)} \| p^{(T)})\) is the KL divergence between the EMA teacher's and student's soft distributions at temperature \(T\).

This is the paper's core contribution. None of \(\mathcal{L}_{KD}\), the warm-start schedule \(\lambda_e\), the temperature \(T\), or the EMA teacher appear anywhere in Eqs. 14–58. The proof analyzes a generic \(f\) that could be any smooth function. A proof meant to support this paper's contribution must show that using \(\mathcal{L}_{KD}\) helps (or at least does not hurt) convergence compared to \(\mathcal{L}_{CE}\) alone.

2. The EMA teacher is entirely missing

Algorithm 1 maintains an EMA teacher model \(\theta_t\) updated every epoch:

Algorithm 1 — EMA update (end of each epoch)
\[\theta_t^e = \beta \cdot \theta_t^{e-1} + (1-\beta) \cdot \theta_s^e \quad (\beta = 0.99)\]

The teacher is not trained by gradient descent; it is an exponential moving average of the student weights. The proof has no such object. The \(\beta_K\) in Eq. 39 is presumably unrelated (and undefined), but even if it were intended to model EMA decay, the structure of EMA (not a gradient update but a convex combination) is fundamentally different from any gradient step in the proof.

Notation Collision

In many equations including Eq. 28, the letter \(L\) simultaneously denotes:

  • The Lipschitz constant of \(\nabla f\) (L-smoothness)
  • The number of local update steps per client per round

In Eq. 28 the term \(-(1/6)KL\eta\|\nabla f\|^2\), the first \(L\) is the step count, while L in the coefficient \(2L\eta^2K\) is the smoothness constant. These are two different mathematical objects. One should be renamed (e.g., use \(\ell\) for local steps, or \(E\) as in Algorithm 1 which uses \(E_\text{train}\)).

What IS Correct

The following components are standard and correctly applied for a parallel SGD / FedAvg-style analysis:

L-smoothness descent lemma (Eq. 14)  ·  Young's inequality (Eqs. 16–17)  ·  4-term decomposition structure (Eqs. 18, 29–36)  ·  Variance bound (Eqs. 19–20)  ·  Local drift bound (Eqs. 21–24)  ·  Weighted averaging lemma (Eqs. 48–52)  ·  Convergence rate form \(O(1/\sqrt{KLR})\)

Recommended Fix Structure

For a proof that actually covers Algorithm 1, the following structure is needed: Assumption 1 L-smoothness of f (keep as-is, Eq. 14 form) Assumption 2 Bounded variance of stochastic gradients σ² (keep) Assumption 3 (NEW) Bounded data heterogeneity across K clients: ζ² Assumption 4 (NEW) EMA teacher approximation quality: ‖θ_t^e - θ_s^e‖ ≤ δ_e (or derive from β=0.99 formula) Assumption 5 (NEW) KD loss alignment: when the teacher is well-trained, ‖∇L_KD - ∇L_CE‖ ≤ ε_KD (or show KD adds no divergence) Lemma 1 (Sequential one-client descent per round) Only client k is active in round r: prove E[f(θ^{r+1}) - f(θ^r)] ≤ -αE‖∇f‖² + variance terms without K-parallel structure. Lemma 2 (EMA teacher is a valid reference point) Show ‖θ_t - θ_s‖ stays bounded under β=0.99 update. This replaces the undefined β_K in Eq. 39. Lemma 3 (KD loss does not destabilize convergence) Show that adding λ_e·L_KD to L_CE keeps the combined objective L-smooth with the same or related constants. The warm-start schedule (λ_e=0 for e≤w) simplifies this for early rounds. Theorem 1 Sequential convergence: (1/R)Σ_r E‖∇f(θ^r)‖² ≤ O(1/√R) + O(ε_KD) Proof: Lemmas 1–3, telescope over R rounds, set η optimally. □ Note: The empirical results (Table I showing +13.7pp on CIFAR-10) stand independently of the proof issues. The proof is in Appendix A and the empirical contribution does not depend on it.
Most important question before rewriting: With a sequential algorithm, the server model does not receive gradients while client k is training, and when client k+1 starts, the server has drifted from what client k experienced. This non-stationarity — exactly the forgetting the paper studies — is what a correct proof must model. The warm-start KD schedule (\(\lambda_e = 0\) for \(e \leq w\)) suggests the authors know this is delicate; a proof should make it precise.
