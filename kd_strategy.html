KD Paper — Proof Strategy

How to fix or reframe the convergence analysis in Appendix A — and what can stand as-is
May 2, 2026
The key fact: The paper's empirical results are strong and independent of the proof. Table I shows +13.7 percentage points on CIFAR-10 over sequential split learning without KD. Those results do not depend on Appendix A being correct. The strategy question is: what to do with the proof?

Option A vs. Option B

Option A — Fix the proof
  • Rewrite Appendix A to actually analyze Algorithm 1
  • Model sequential client order (not parallel)
  • Include EMA teacher and KD loss in the analysis
  • Requires new analytical work — not a minor edit
  • Result: first rigorous convergence guarantee for sequential split learning with KD
Option B — Reframe as baseline bound
  • Label the existing proof as an "upper bound for the parallel case"
  • Add a brief section noting that sequential training introduces additional drift \(\delta_r\)
  • Claim: the parallel bound + \(O(\delta_r)\) correction frames the sequential setting
  • Lower risk, but weaker — reviewers may ask for the sequential proof directly
For submission to a venue with theory review: Option B may not survive review. A reviewer who reads Algorithm 1 and Appendix A will immediately notice the sequential/parallel mismatch. Claiming the parallel analysis "upper bounds" the sequential case requires proving the claim — which is itself non-trivial work. Option B is safer for venues focused on empirical results; Option A is required for theory-focused venues.

The Empirical Results Stand Independently

This is the most important strategic point. The paper's contribution is primarily empirical:

  • Algorithm 1 (sequential split learning + EMA-guided KD) is novel
  • Table I demonstrates +13.7pp on CIFAR-10, with consistent gains on CIFAR-100 and other datasets
  • The forgetting problem in sequential split learning is a real and documented issue
  • The EMA teacher + KD approach is a clean, practical solution

None of this depends on Appendix A. If the paper is submitted to an applications or systems venue (AAAI, ICLR workshop, IEEE FL workshop), reviewers may not scrutinize the appendix proof. The paper can be submitted as-is with the caveat that the convergence analysis is exploratory.

Recommended framing for submission: In the paper text, do not overclaim the proof. The appendix should be labeled "Exploratory Convergence Analysis" or "Motivation for the KD design" rather than "Theorem." This sets accurate reviewer expectations and protects the strong empirical results from being undermined by proof issues.

What a Correct Proof Would Need to Model

A convergence proof that actually supports Algorithm 1 faces three challenges that the current proof does not address. These are listed in order of difficulty:

Challenge 1: Sequential non-stationarity (hardest)

In Algorithm 1, when client \(k\) trains, the server's task is to support client \(k\)'s representation. When client \(k+1\) starts, the server must shift — this is forgetting. The server's effective loss landscape changes between client rounds. A proof must model this non-stationarity explicitly.

What a correct proof must bound
Define the server's loss under client \(k\)'s distribution as \(f_k(\theta_s)\). After client \(k\) trains, before client \(k+1\) begins, the server's parameters \(\theta_s\) have drifted toward \(\arg\min f_k\). But client \(k+1\) needs \(\arg\min f_{k+1}\). The gap \(\|\arg\min f_k - \arg\min f_{k+1}\|\) is the source of forgetting. The proof must bound how KD controls this drift.

Challenge 2: EMA teacher as a reference point (moderate difficulty)

The EMA teacher \(\theta_t\) is not trained by gradient descent. It is a convex combination of past student weights. To include it in a convergence proof, one must either:

  • Show that \(\theta_t\) tracks the student closely: \(\|\theta_t^e - \theta_s^e\| \leq \delta_e\) for some bounded \(\delta_e\) (derivable from the EMA formula with \(\beta = 0.99\))
  • Or treat the KD loss \(\mathcal{L}_{KD} = T^2 \cdot KL(q^{(T)}\|\theta_t)\) as a regularizer with a slowly-moving reference, and bound its gradient
EMA drift bound (derivable)
Under the EMA update \(\theta_t^e = \beta \theta_t^{e-1} + (1-\beta)\theta_s^e\) with \(\beta = 0.99\):
\[\|\theta_t^e - \theta_s^e\| = \|\beta\theta_t^{e-1} + (1-\beta)\theta_s^e - \theta_s^e\| = \beta\|\theta_t^{e-1} - \theta_s^e\|\] If gradients are bounded (\(\|\nabla f\| \leq G\)), then \(\|\theta_t^e - \theta_s^e\|\) stays bounded by \(O(\eta G / (1-\beta))\). This can be derived explicitly.

Challenge 3: KD loss smoothness (easier)

The KD loss \(\mathcal{L}_{KD} = T^2 \cdot KL(q^{(T)}\|p^{(T)})\) must be shown to be L-smooth (or have bounded gradient norm) for the combined objective to satisfy the L-smoothness assumption. The KL divergence between softmax distributions is well-behaved when the teacher is stable (EMA ensures this). This is likely the most tractable part of a correct proof.

KD loss gradient
\[\nabla_{\theta_s} \mathcal{L}_{KD} = T^2 \nabla_{\theta_s} KL(q^{(T)} \| p^{(T)})\] where \(p^{(T)} = \text{softmax}(z_s / T)\), \(q^{(T)} = \text{softmax}(z_t / T)\), and \(z_s, z_t\) are the student and teacher logits. The gradient is bounded when logits are bounded — a standard assumption in deep learning theory.

The Hardest Gap: f is Non-Stationary

This is the most fundamental theoretical obstacle. The warm-start schedule sets:

Warm-start schedule
\[\lambda_e = 0 \text{ for } e \leq w, \quad \lambda_e \text{ ramps to } \lambda_{\max} \text{ for } e > w\] Combined loss: \(\mathcal{L}_e = (1-\lambda_e)\mathcal{L}_{CE} + \lambda_e \mathcal{L}_{KD}\)

Because \(\lambda_e\) changes with epoch \(e\), the objective function changes during training. Standard SGD convergence analysis requires a fixed objective \(f\). There are two ways to handle this:

Phase separation approach

Analyze each phase separately:

Phase 1 (\(e \leq w\)): \(\mathcal{L} = \mathcal{L}_{CE}\) — standard cross-entropy SGD. Proven convergence.

Phase 2 (\(e > w\)): \(\mathcal{L} = (1-\lambda)\mathcal{L}_{CE} + \lambda\mathcal{L}_{KD}\) for fixed \(\lambda = \lambda_{\max}\). Smooth if \(\mathcal{L}_{KD}\) is smooth.

Connect: Phase 1 gives a warm starting point for Phase 2.

Cleaner and more rigorous; requires two separate analyses
Slowly-varying objective approach

Treat the changing \(\lambda_e\) as a slowly-varying perturbation:

If \(|\lambda_{e+1} - \lambda_e| \leq \delta\) (bounded rate of change), then the objective changes slowly, and convergence results for slowly-varying objectives apply.

This is a known technique in online learning and non-stationary optimization.

More general; harder to make rigorous for a specific schedule

For Submission: Recommended Actions

1
Protect the empirical results (immediate)

The paper's empirical contribution is strong and self-contained. Do not weaken it by over-linking it to the proof. In the paper body, present Table I and the algorithm clearly. In the appendix, explicitly label the convergence analysis as "motivation" or "analysis for the parallel approximation case" to set accurate expectations.

2
Decide: fix or reframe the proof

For empirical venues (FL workshops, applied ML conferences): Option B (reframe as baseline bound) is sufficient. Add a sentence noting that "a complete sequential convergence analysis is future work." For theory venues (Involve, JMLR, NeurIPS theory track): Option A is required.

3
If pursuing Option A: start with the EMA lemma

The EMA drift bound is the most tractable piece (see Challenge 2 above). Deriving \(\|\theta_t^e - \theta_s^e\| \leq O(\eta G/(1-\beta))\) from the \(\beta=0.99\) formula is elementary and can be done immediately. This gives the proof a solid foundation. The sequential non-stationarity (Challenge 1) is the hardest piece and should be last.

4
Define what f is, precisely

The hardest prerequisite: what is the global objective \(f\) for this algorithm? Is it \(\sum_{k=1}^K f_k(\theta_s)\) where \(f_k\) is client \(k\)'s loss? Is it \((1-\lambda)\mathcal{L}_{CE} + \lambda\mathcal{L}_{KD}\) for fixed \(\lambda\)? Until this is defined, no proof structure can be written. The answer determines everything downstream.

5
Fix the minor issues in the existing proof regardless

The notation collision (L = smoothness AND local steps), the undefined \(\beta_K\), the skipped algebra in Eq. 39→41, and the broken assumption references in Theorem 1 should all be fixed. These are editorial issues independent of the bigger structural problems. Fix them first — they are fast and unambiguous.

The core strategic insight: The most impactful proof addition for this paper — more than any algebraic cleanup — is a lemma showing that the EMA teacher with \(\beta = 0.99\) stays close to the student, and therefore \(\mathcal{L}_{KD}\) acts as a bounded regularizer rather than a disruptive term.
