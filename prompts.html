Math + writing
"both" — Section 2 (Related Work) AND Lemma 2 (Client Drift Bound)
Section 2 — Related Work: Four subsections: (2.1) BP-free learning (Feedback Alignment, Target Propagation, Greedy Layer-wise, Forward-Forward, Huang 2025); (2.2) Federated convergence (FedAvg, Li 2020, SCAFFOLD); (2.3) Split networks (Vepakomma 2018 — BP-free is strictly more private); (2.4) Approximate gradient convergence (Ajalloeian & Stich 2020 — key distinction: β is controllable, unlike fixed stochastic bias).

Lemma 2 (Client Drift Bound): Telescope K local updates, bound each auxiliary gradient ‖g‖ ≤ G+β, apply triangle inequality → ‖w^(i)_{t,K} − w_t‖ ≤ Kη(G+β). Squaring: ‖·‖² ≤ K²η²(G+β)². Corollary 2.1 extends to aggregated model via Jensen. Key insight: β and G contribute additively — poor auxiliary networks act as if each client has a systematically larger effective gradient.

A7
Math
"yes" — Lemma 3 (Aggregation Error), Lemma 4 (Telescoping), and Main Theorem
Lemma 3 (Aggregation Error Bound): Defines Ĝ_t = (1/KN)Σg^(i)_{t,k}. Decomposes Ĝ_t − ∇F(w_t) into 3 sources: gradient drift within local steps, auxiliary error δ, and client heterogeneity. Proves ‖Ĝ_t − ∇F(w_t)‖² ≤ L²K²η²(G+β)²/2 + 2β² + 2σ²_h. Heterogeneity floor σ²_h is irreducible; β² and drift term are controllable.

Lemma 4 + Theorem 1: Applies descent lemma to effective update, uses Young's inequality, telescopes over T rounds → (1/T)Σ‖∇F‖² ≤ 4(F₀−F*)/(KηT) + Ξ. Setting η = c/(K√T): min_t ‖∇F(wₜ)‖² ≤ 8L(F₀−F*)/√T + C₁β² + C₂σ²_h. Rate term → 0, drift → 0 faster, β² and σ²_h form the irreducible floor. Recovers FedAvg exactly when β=0.
Lemma 3 proved Lemma 4 proved Theorem 1 complete

Writing
"yes" — Section 5 (Design Implications) and Section 6 (Numerical Experiments)
Section 5 — Design Implications: To achieve ε-accuracy: need T ≥ 64L²(F₀−F*)²/ε² rounds AND β ≤ √(ε/2C₁). Corollary 5.1: halving ε requires reducing β by only 1/√2 (favorable square-root). Corollary 5.2: when σ²_h > β², improving auxiliary nets yields no benefit — heterogeneity is the binding constraint. Optimal K* = (σ²_h + β²)^(1/2) / (Lη(G+β)). Privacy: no gradient crosses client-server boundary; DP noise fits as additional β² term.

Section 6 — Numerical Experiments: MNIST, N=10 clients, 3-layer MLP, Dirichlet partition. Three experiments: (1) log-log slope ≈ −0.5 confirms O(1/√T); (2) final error vs β² slope ≈ +1 confirms O(β²) floor; (3) gap between weak/strong aux nets closes at σ²_h ≈ β̂², confirming Corollary 5.2.
