Proof Fitness Analysis

Does the convergence proof match the algorithm in Decoupled Split Learning via Auxiliary Loss?
Paper: Zihad, Owino, Tang, Huang (Montclair State / SUSTech)  ·  Reviewed May 2, 2026
What this page answers: The paper (by Dr. Huang's group) describes an algorithm — Decoupled Split Learning (DSL) — but provides no formal convergence proof, only an informal appeal to greedy layer-wise training literature. Benjamin's proof is attempting to fill that gap. This page evaluates how well the proof actually fits the algorithm it claims to analyze.

What Maps Correctly

Component correspondence

The paper trains three modules. The proof has three corresponding objective functions. The mapping is direct:

Paper moduleProof componentRoleFit
\(M_b\) — client bottom model \(F_b(\theta_b)\) Client-side feature extractor, optimized with auxiliary loss Good fit
\(C_a\) — auxiliary classifier \(F_a(\theta_a)\) Shallow head at cut layer, generates local loss signal Good fit
\(M_t\) — server top model \(F_t(\theta_t)\) Server model, optimized with global classification loss Good fit

Server convergence (Ft) — well-matched

The paper's server update is:

Algorithm 1, lines 18–20
\[\mathcal{L} = \frac{1}{B}\sum_i \mathcal{L}(\hat{y}_i, y_i), \quad \theta_t \leftarrow \theta_t - \eta_t \nabla_{\theta_t}\mathcal{L}\]

This is exactly standard SGD on a fixed-input loss, which is precisely what Section 2.3 of the proof analyzes. The server receives activations \(z_i\) from the client and treats them as fixed inputs for its own optimization. The Ft convergence proof correctly captures this.

Right spirit: auxiliary gradient as surrogate

The core idea of the proof — that the client uses \(\nabla F_a\) (gradient of auxiliary loss) as a local signal instead of the true global gradient — correctly captures what the paper does. The paper explicitly says the client "computes its own gradient immediately after the forward pass using the auxiliary loss" without waiting for the server. The proof's auxiliary bias assumption is the right framework for formalizing this.

The Deep Mismatch: Two Objectives, Not One

This is the most fundamental problem. The paper's DSL algorithm optimizes two completely separate objectives:

Paper (Client)
Client minimizes:
\[\mathcal{L}_\text{aux}(C_a(M_b(x)), y)\] This is the auxiliary cross-entropy loss. The client never sees \(\mathcal{L}\) — the true global loss.
Proof (Global)
Proof analyzes convergence of:
\[\frac{1}{T}\sum_{K=0}^{T-1}\|\nabla F^K\|^2\] where \(F\) is a single global objective over \((\theta_b, \theta_a, \theta_t)\) that is never defined.

The proof assumes a global objective \(F(\theta_b, \theta_a, \theta_t)\) exists and that the gradient of the auxiliary network \(\nabla F_a\) approximates \(\nabla_{\theta_b} F\) up to bounded error \(\varepsilon\). But the paper's system does not have a single \(F\). The client never computes \(\nabla_{\theta_b}\mathcal{L}\) — not even approximately. It computes \(\nabla_{\theta_b}\mathcal{L}_\text{aux}\), which is a genuinely different objective, not a noisy version of the true one.

Key mismatch: The auxiliary bias assumption (eq. 7) says
\[\|\mathbb{E}[\nabla F_a(\theta_a;\xi_a)] - \nabla_{\theta_b}F(\theta_b,\theta_a,\theta_t)\| \leq \varepsilon\] This says \(\nabla \mathcal{L}_\text{aux}\) approximates \(\nabla \mathcal{L}\) with small error. But the paper's design does not require this. In DSL, \(\mathcal{L}_\text{aux}\) is a different objective that happens to predict the same labels — not an approximation of the global loss gradient. Whether this gap is small or large depends on how good \(C_a\)'s representation is, which varies during training.

The Moving Target Problem

The paper's Section III.C acknowledges an important coupling: "\(M_t\) is trained to perform the final prediction given those features [from \(M_b\)]." This means as \(\theta_b\) is updated, the activations \(z = M_b(x)\) change — which means \(M_t\) is optimizing a moving target at every round.

The proof's \(F_t\) convergence (Section 2.3) treats the input \(z\) as fixed, which is correct for a single round. But across rounds, as \(\theta_b\) updates, the server's optimization landscape shifts. This is a non-stationarity that standard SGD convergence analysis does not handle and the proof does not address at all.

Reality (paper)
Round \(K\): Server minimizes \(\mathcal{L}(M_t(M_b^K(x)), y)\)

Round \(K+1\): Server minimizes \(\mathcal{L}(M_t(M_b^{K+1}(x)), y)\)

The server's input distribution changes every round because \(M_b\) is updating simultaneously.
Proof assumption
\(\theta_t^{K+1} = \theta_t^K - \eta\nabla F_t(\theta_t^K; \xi_t^K)\)

This assumes a fixed objective \(F_t\) — the input \(z\) is treated as stationary. The proof never accounts for \(M_b\) changing.

Handling this correctly requires bounding the drift in \(M_t\)'s objective caused by changes in \(M_b\) — something analogous to client drift bounds in FedAvg analysis. This is a legitimate open problem in the greedy/decoupled training literature, and it's why the paper appeals informally to [3] rather than proving convergence directly.

The Separate Learning Rates Problem

The proof sets a single learning rate:

Assumptions section
\[\eta = \min\!\left(\frac{1}{L_1}, \frac{1}{L_2}, \frac{1}{L_3}\right)\]

The paper uses separate learning rates \(\eta_b\) for the client (applied to \(\theta_b\) and \(\theta_a\)) and \(\eta_t\) for the server. These can in principle be different — the client and server are independent. The proof's single-\(\eta\) assumption is a simplification that removes a key design parameter the paper explicitly includes.

What the Proof Gets Right About the Paper's Contribution

Despite the gaps, the proof correctly identifies and formalizes the paper's key claim:

  1. The 50% communication reduction is justified by the proof's structure. Since the proof shows Fb, Fa, and Ft each converge using only local gradient information — with no backward signal from server to client — the communication pattern is one-directional by construction. This matches the paper's Algorithm 1.
  2. The O(1/T) convergence rate is the right target. The paper uses SGD with momentum; the proof's O(1/T) rate for nonconvex SGD is the correct asymptotic behavior to prove.
  3. The irreducible bias floor is the right concept. The proof's \(3e^2\) floor captures the fact that using \(\mathcal{L}_\text{aux}\) instead of \(\mathcal{L}\) introduces a permanent gap that doesn't vanish with more training. This is exactly the "performance parity" claim in the paper (Observation 1) — DSL never quite matches CSL because the client's gradient signal is an approximation.

What a Correct Proof for This Paper Would Look Like

A convergence proof that properly matches the DSL algorithm needs to handle the two-objective structure directly. The right framework is a bi-level or alternating optimization analysis:

Required elementWhy it's neededStatus in current proof
Define \(F\) as a weighted sum \(\mathcal{L}_\text{aux} + \lambda \mathcal{L}\) Creates a single differentiable objective that both client and server contribute to Not present
Bound \(\|\nabla_{\theta_b}\mathcal{L}_\text{aux} - \nabla_{\theta_b}\mathcal{L}\|\) This is the true auxiliary bias — how well does the auxiliary gradient approximate the global one? Assumed but not derived
Moving target lemma for \(M_t\) Bounds how much \(M_t\)'s loss landscape shifts per round as \(M_b\) updates Not present
Separate \(\eta_b\), \(\eta_t\) learning rates Matches the actual algorithm; different rates may be needed for stability Collapsed to single \(\eta\)
Server-side Ft convergence Server trains independently on received activations Correct as-is
Auxiliary Fa convergence Auxiliary head trains with client on local loss Correct as-is

Bottom Line

The proof analyzes an idealized version of DSL, not DSL itself. It treats the auxiliary gradient as a bounded approximation of the true global gradient — which is the right conceptual model, but requires a justification the paper doesn't provide and the proof doesn't derive. The server-side analysis is clean and correct. The client-side analysis is mathematically valid but rests on an assumption (eq. 7) whose fitness to the actual algorithm is unverified.

This is not a fatal flaw — it is actually a legitimate research gap that the proof is trying to fill. The paper by Zihad et al. acknowledges the convergence question is open (Section III.C says only that the approach "can approximate the globally optimal solution" based on greedy learning insights from [3]). A rigorous proof that pins down when and how well \(\nabla \mathcal{L}_\text{aux}\) approximates \(\nabla_{\theta_b}\mathcal{L}\) would be a genuine theoretical contribution to the paper's missing analysis.

The most productive next step is to work with Dr. Huang to either:

  1. Derive a bound on the auxiliary bias from first principles — show that if \(C_a\) achieves low auxiliary loss, then \(\|\nabla_{\theta_b}\mathcal{L}_\text{aux} - \nabla_{\theta_b}\mathcal{L}\|\) is small. This would transform the assumption into a lemma.
  2. Or reframe the proof goal — instead of claiming convergence to the global optimum of \(\mathcal{L}\), prove convergence of each component to its own local optimum, and bound the gap between the local and global solutions separately.
