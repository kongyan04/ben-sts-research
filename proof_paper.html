Convergence Analysis for BP-Free with Auxiliary Network
Benjamin Qin
Advised by Dr. Chao Huang
April 2026

1Assumptions

For our new algorithm, we can somewhat base it in the original Split Learning framework; using the standard \(L\)-Smoothness assumption for the Client, Auxiliary, and Server sides with three different smoothness constants; that is,

\begin{equation} F_b(\theta_b) \leq F_b(\theta_c) + (\theta_b - \theta_c)^T \nabla F_b(\theta_c) + \frac{L_1}{2}\|\theta_b - \theta_c\|^2 \end{equation} \begin{equation} F_a(\theta_a) \leq F_a(\theta_d) + (\theta_a - \theta_d)^T \nabla F_a(\theta_d) + \frac{L_2}{2}\|\theta_a - \theta_d\|^2 \end{equation}

and

\begin{equation} F_t(\theta_t) \leq F_t(\theta_s) + (\theta_t - \theta_s)^T \nabla F_t(\theta_s) + \frac{L_3}{2}\|\theta_t - \theta_s\|^2 \end{equation}

We define \(F\) as the overall objective function for the entire model. For these assumptions, \(\theta_t, \theta_b,\) and \(\theta_a\) are parameters of the three sections of the model, \(L_1, L_2,\) and \(L_3\) are the respective smoothness constants, and \(F_b, F_a,\) and \(F_t\) are the respective objective functions of each component. In addition, we need to assume that the variance of the stochastic gradients of each client with data for the three components of the model are bounded by

\begin{equation} \mathbb{E}\!\left[\|\nabla F_b(\theta_b^{K_1};\xi_b^{K_1}) - \nabla F_b(\theta_b^{K_1})\|^2\right] \leq \sigma_b^2 \end{equation} \begin{equation} \mathbb{E}\!\left[\|\nabla F_a(\theta_a^{K_2};\xi_a^{K_2}) - \nabla F_a(\theta_a^{K_2})\|^2\right] \leq \sigma_a^2 \end{equation} \begin{equation} \mathbb{E}\!\left[\|\nabla F_t(\theta_t^{K_3};\xi_t^{K_3}) - \nabla F_t(\theta_t^{K_3})\|^2\right] \leq \sigma_t^2 \end{equation}

where \(K_1, K_2,\) and \(K_3\) are the respective numbers of machines in each component of the model. Importantly, we set \[ \eta = \min\!\left(\frac{1}{L_1},\, \frac{1}{L_2},\, \frac{1}{L_3}\right). \] One last thing we need to assume before we start the convergence proof is that the auxiliary network backpropagation mirrors the backpropagation of a traditional split learning model with only one cut between the client and server sides within a bounded bias. To do this, we assume

\begin{equation} \|\mathbb{E}[\nabla F_a(\theta_a;\xi_a)] - \nabla_{\theta_b} F(\theta_b,\theta_a,\theta_t)\| \leq \varepsilon \end{equation}

to bound the auxiliary bias for an \(\varepsilon \geq 0\) that is very small with respect to the equivalent backpropagation if there was only one cut between the client and server sides instead of the two cuts; between the auxiliary and remaining client side, and the remaining client side and the server side.

2Proof

To begin the proof, we will attempt to prove a collective convergence bound using the assumptions mentioned above.

2.1   \(F_b\) convergence

For \(F_b\), we use the \(L\)-smoothness assumption from above:

\begin{equation} F_b(\theta_b) \leq F_b(\theta_c) + (\theta_b - \theta_c)^T \nabla F_b(\theta_c) + \frac{L_1}{2}\|\theta_b - \theta_c\|^2 \end{equation}

Then using the fact that

\begin{equation} \theta_b^{K+1} = \theta_b^K - \eta\nabla F_b(\theta_b^K;\xi_b^K) \end{equation}

we get

\begin{equation} F_b(\theta_b^{K+1}) \leq F_b(\theta_b^K) - \eta\nabla F_b(\theta_b^K;\xi_b^K)^T \nabla F_b(\theta_b^K) + \frac{L_1}{2}\|-\eta\nabla F_b(\theta_b^K;\xi_b^K)\|^2 \end{equation}

We can simplify this to

\begin{equation} F_b(\theta_b^{K+1}) \leq F_b(\theta_b^K) - \eta\nabla F_b(\theta_b^K;\xi_b^K)^T \nabla F_b(\theta_b^K) + \frac{L_1\eta^2}{2}\|\nabla F_b(\theta_b^K;\xi_b^K)\|^2 \end{equation}

From here, we take the expectation of both sides, using the linearity of expectation and the definition of matrix transposes to get:

\begin{equation} \mathbb{E}[F_b^{K+1}] \leq \mathbb{E}\!\left[F_b(\theta_b^K) - \eta\|\nabla F_b(\theta_b^K)\|^2 + \frac{L_1\eta^2}{2}\|\nabla F_b(\theta_b^K;\xi_b^K)\|^2\right] \end{equation}

Next, we use Bias-Variance Decomposition,

\begin{equation} \mathbb{E}[\|X\|^2] = \|\mathbb{E}[X]\|^2 + \mathbb{E}[\|X - \mathbb{E}[X]\|^2] \end{equation}

where \(X\) is a stochastic sample, to simplify

\begin{align*} &\mathbb{E}\!\left[\frac{L_1\eta^2}{2}\|\nabla F_b(\theta_b^K;\xi_b^K)\|^2 - \eta\|\nabla F_b(\theta_b^K)\|^2\right] \\ &= \mathbb{E}\!\left[\frac{L_1\eta^2}{2}\!\left(\|\nabla F_b(\theta_b^K)\|^2 + \sigma_b^2\right) - \eta\|\nabla F_b(\theta_b^K)\|^2\right] \\ &= \mathbb{E}\!\left[\left(\frac{L_1\eta^2}{2} - \eta\right)\|\nabla F_b(\theta_b^K)\|^2 + \frac{L_1\eta^2\sigma_b^2}{2}\right] \end{align*}

To finish out the \(F_b\) convergence, we sum:

\begin{equation} \mathbb{E}[F_b^{K+1}] \leq \mathbb{E}\!\left[F_b(\theta_b^K) + \left(\frac{L_1\eta^2}{2} - \eta\right)\|\nabla F_b(\theta_b^K)\|^2 + \frac{L_1\eta^2\sigma_b^2}{2}\right] \end{equation}

over \(T\) rounds:

\begin{equation} \sum_{K=0}^{T-1}\mathbb{E}[F_b^{K+1} - F_b(\theta_b^K)] \leq \left(\frac{L_1\eta^2}{2} - \eta\right)\sum_{K=0}^{T-1}\|\nabla F_b(\theta_b^K)\|^2 + \frac{TL_1\eta^2\sigma_b^2}{2} \end{equation}

The left-hand side telescopes because all but the first and last terms cancel: \(\mathbb{E}[F_b^T] - F_b(\theta_b^0).\) We remove the expectation around \(F_b(\theta_b^0)\) because \(\mathbb{E}[F_b(\theta_b^0)] = F_b(\theta_b^0)\); the initial weights are a constant. Rearranging:

\begin{equation} \frac{1}{T}\sum_{K=0}^{T-1}\mathbb{E}\!\left[\|\nabla F_b(\theta_b^K)\|^2\right] \leq \frac{L_1\eta^2\sigma_b^2}{2\!\left(\eta - \frac{L_1\eta^2}{2}\right)} + \frac{F_b(\theta_b^0) - F_b^*}{T\!\left(\eta - \frac{L_1\eta^2}{2}\right)} \end{equation}

where \(F_b^* \leq \mathbb{E}[F_b^T]\) is the global minimum of \(F_b\). We require \(\eta < 2/L_1\) so the denominators are positive. Setting \(\eta \leq 1/L_1\) simplifies the right side to:

\begin{equation} \frac{1}{T}\sum_{K=0}^{T-1}\mathbb{E}\!\left[\|\nabla F_b(\theta_b^K)\|^2\right] \leq \sigma_b^2 + \frac{2L_1(F_b(\theta_b^0) - F_b^*)}{T} \end{equation}

2.2   \(F_a\) convergence

Similar to above, we use the \(L\)-smoothness assumption:

\begin{equation} F_a(\theta_a) \leq F_a(\theta_d) + (\theta_a - \theta_d)^T \nabla F_a(\theta_d) + \frac{L_2}{2}\|\theta_a - \theta_d\|^2 \end{equation}

Then using

\begin{equation} \theta_a^{K+1} = \theta_a^K - \eta\nabla F_a(\theta_a^K;\xi_a^K) \end{equation}

we get

\begin{equation} F_a(\theta_a^{K+1}) \leq F_a(\theta_a^K) - \eta\nabla F_a(\theta_a^K;\xi_a^K)^T \nabla F_a(\theta_a^K) + \frac{L_2\eta^2}{2}\|\nabla F_a(\theta_a^K;\xi_a^K)\|^2 \end{equation}

Taking the expectation and applying the bias-variance decomposition as in Section 2.1:

\begin{equation} \mathbb{E}[F_a^{K+1}] \leq \mathbb{E}\!\left[F_a(\theta_a^K) + \left(\frac{L_2\eta^2}{2} - \eta\right)\|\nabla F_a(\theta_a^K)\|^2 + \frac{L_2\eta^2\sigma_a^2}{2}\right] \end{equation}

Summing over \(T\) rounds and telescoping the left-hand side:

\begin{equation} \sum_{K=0}^{T-1}\mathbb{E}[F_a^{K+1} - F_a(\theta_a^K)] \leq \left(\frac{L_2\eta^2}{2} - \eta\right)\sum_{K=0}^{T-1}\|\nabla F_a(\theta_a^K)\|^2 + \frac{TL_2\eta^2\sigma_a^2}{2} \end{equation}

Rearranging with \(\eta \leq 1/L_2\):

\begin{equation} \frac{1}{T}\sum_{K=0}^{T-1}\mathbb{E}\!\left[\|\nabla F_a(\theta_a^K)\|^2\right] \leq \sigma_a^2 + \frac{2L_2(F_a(\theta_a^0) - F_a^*)}{T} \end{equation}

where \(F_a^* \leq \mathbb{E}[F_a^T]\) is the global minimum of \(F_a\). Note that this convergence affects \(F_b\)'s update: the auxiliary network's gradient signal drives the update of the client-side model \(F_b\) in the global analysis.

2.3   \(F_t\) convergence

Similar to above, we use the \(L\)-smoothness assumption:

\begin{equation} F_t(\theta_t) \leq F_t(\theta_s) + (\theta_t - \theta_s)^T \nabla F_t(\theta_s) + \frac{L_3}{2}\|\theta_t - \theta_s\|^2 \end{equation}

Then using

\begin{equation} \theta_t^{K+1} = \theta_t^K - \eta\nabla F_t(\theta_t^K;\xi_t^K) \end{equation}

we get

\begin{equation} F_t(\theta_t^{K+1}) \leq F_t(\theta_t^K) - \eta\nabla F_t(\theta_t^K;\xi_t^K)^T \nabla F_t(\theta_t^K) + \frac{L_3\eta^2}{2}\|\nabla F_t(\theta_t^K;\xi_t^K)\|^2 \end{equation}

Taking the expectation and applying the bias-variance decomposition:

\begin{equation} \mathbb{E}[F_t^{K+1}] \leq \mathbb{E}\!\left[F_t(\theta_t^K) + \left(\frac{L_3\eta^2}{2} - \eta\right)\|\nabla F_t(\theta_t^K)\|^2 + \frac{L_3\eta^2\sigma_t^2}{2}\right] \end{equation}

Summing over \(T\) rounds and telescoping:

\begin{equation} \sum_{K=0}^{T-1}\mathbb{E}[F_t^{K+1} - F_t(\theta_t^K)] \leq \left(\frac{L_3\eta^2}{2} - \eta\right)\sum_{K=0}^{T-1}\|\nabla F_t(\theta_t^K)\|^2 + \frac{TL_3\eta^2\sigma_t^2}{2} \end{equation}

Rearranging with \(\eta \leq 1/L_3\):

\begin{equation} \frac{1}{T}\sum_{K=0}^{T-1}\mathbb{E}\!\left[\|\nabla F_t(\theta_t^K)\|^2\right] \leq \sigma_t^2 + \frac{2L_3(F_t(\theta_t^0) - F_t^*)}{T} \end{equation}

where \(F_t^* \leq \mathbb{E}[F_t^T]\) is the global minimum of \(F_t\).

2.4   Putting it all together

We derive the global convergence from the overall \(L\)-smoothness assumption:

\begin{equation} F^{K+1} \leq F^K - \eta(\nabla F_a(\theta_a))^T\nabla F^K + \frac{L_\text{overall}}{2}\|-\eta\nabla F_a\|^2 \end{equation}

where

\begin{equation} L_\text{overall} = \max(L_1, L_2, L_3) \end{equation}

Taking the expectation of both sides and applying the auxiliary bias assumption:

\begin{equation} \mathbb{E}[F^{K+1}] \leq \mathbb{E}\!\left[F^K - \eta(\nabla F^K + e)^T\nabla F^K + \frac{L_\text{overall}\eta^2}{2}\|\nabla F^K + e + \xi\|^2\right] \end{equation}

where \(e\) is a vector with \(\|e\| = \varepsilon\). Using a similar mathematical logic to Sections 2.1–2.3, we further develop this to:

\begin{equation} \mathbb{E}[F^{K+1} - F^K] \leq \mathbb{E}\!\left[-\eta\|\nabla F^K\|^2 - \eta e^T\nabla F^K + \frac{L_\text{overall}\eta^2\!\left(\|\nabla F^K\|^2 + 2\|\nabla F^K e + e^2 + \xi^2\right)}{2}\right] \end{equation}

Using the Cauchy-Schwarz and AM-GM inequality:

\begin{equation} \mathbb{E}[F^{K+1} - F^K] \leq \mathbb{E}\!\left[-\eta\|\nabla F^K\|^2 + \frac{\eta}{2}(e^2 + \|\nabla F^K\|^2) + L_\text{overall}\eta^2\!\left(\|\nabla F^K\|^2 + e^2 + \frac{\sigma_\text{overall}^2}{2}\right)\right] \end{equation}

where \(\eta \leq \dfrac{1}{4L_\text{overall}}\) ensures a negative descent coefficient, and

\[ \sigma_\text{overall}^2 = \sigma_b^2 + \sigma_a^2 + \sigma_t^2. \]

Simplifying:

\begin{equation} \mathbb{E}[F^{K+1} - F^K] \leq \mathbb{E}\!\left[-\frac{\eta}{4}\|\nabla F^K\|^2 + \frac{3\eta}{4}e^2 + \frac{\sigma_\text{overall}^2}{2}\right] \end{equation}

Summing over all \(T\) rounds:

\begin{equation} \mathbb{E}[F^T] - F^0 \leq -\frac{\eta}{4}\sum_{K=0}^{T-1}\|\nabla F^K\|^2 + \frac{3\eta}{4}(Te^2) + \frac{T\sigma_\text{overall}^2}{2} \end{equation}

Averaging to get the mean gradient norm:

\begin{equation} \frac{1}{T}\sum_{K=0}^{T-1}\|\nabla F^K\|^2 \leq \frac{4(F^0 - F^*)}{\eta T} + 3e^2 + 2L_\text{overall}\eta\sigma_\text{overall}^2 \end{equation}

This result provides the convergence bound for the two-cut split learning model as a "BP-Free" model. Stated formally:

Theorem 1.
\[ \frac{1}{T}\sum_{K=0}^{T-1}\|\nabla F^K\|^2 \leq \frac{4(F^0 - F^*)}{\eta T} + 3e^2 + 2L_\text{overall}\eta\sigma_\text{overall}^2 \] where \[ \eta \leq \frac{1}{4L_\text{overall}},\quad L_\text{overall} = \max(L_1,L_2,L_3),\quad \sigma_\text{overall}^2 = \sigma_b^2 + \sigma_a^2 + \sigma_t^2,\quad \|e\| = \varepsilon. \]

Our convergence analysis proves that the two-cut "BP-Free" model has an \(O(1/T)\) convergence rate with bounded variance and bias which do not cause the model to diverge. Overall, we have proven that the two-cut "BP-Free" model is as efficient as the standard Split Learning model and its variance and bias are not a significant hindrance.
